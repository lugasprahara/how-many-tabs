An honest confession, in digits only: how many browser tabs are open right now. The program tallies the open windows pile by pile — the work window, the research spiral, and the "later" window nobody has touched in weeks — and writes the single resulting count, nothing else, to the entry file. No rounding, no tidying up first.

## Run it

```sh
node main.ts
```
